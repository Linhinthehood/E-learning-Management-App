Overview
Cross-platform Flutter application (inspired by Google Classroom) for academic course management at the Faculty of Information Technology.
Key System Rules (Mandatory - Purple Highlighted)

Two roles only: Instructor (single user, credentials: admin/admin) and Students (multiple users)
Content scope: Only IT-related topics (programming, databases, AI) - irrelevant content = 0 points
Mandatory deployments: Android APK (arm64), Windows/macOS executable, and public web version

Core Features (10 points total)
1. Interface Structure (3 layers)

Homepage: Role-based (student: course cards; instructor: dashboard with metrics)
Course Space: 3 tabs (Stream, Classwork, People)
User Profile: Avatar and basic info (real names required)
Semester switcher: Default to current; past semesters read-only for students

2. Data Management (2.0 pts)

Hierarchy: Semester → Course → Group → Student
CSV import with preview/validation (handle duplicates intelligently)
Students can belong to only one group per course

3. Content Distribution (2.0 pts)
Four content types with distinct behaviors:

Announcements: Group-scoped, commentable, view tracking
Assignments: Deadline management, late submissions, attempt limits, grade tracking
Quizzes: Question bank with difficulty levels, randomization, timed attempts
Materials: Course-wide visibility, download tracking

4. Interaction & Notifications (2.0 pts)

Forum: Course-level discussions (no student-to-student direct messaging)
Private messaging: Student ↔ Instructor only
Notifications: In-app (students) + email for key events

5. Analytics & Reports (2.0 pts)

Instructor dashboard with progress charts
CSV export for assignments/quizzes (individual or bulk)
Search/filter/sort on all list views

6. Student Features (2.0 pts)

Personal dashboard (progress tracking, deadlines)
Past semesters: read-only access
